# SOL 500 M2 — Admin Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An admin panel for SOL 500 with three tabs: Game history, Live server and Project progress.
- It opens from an **Admin** button in the browser or the app on the host PC.
- Other Wi-Fi devices can open it with a password.
- It is never reachable through the online share link.

**Architecture:**
- **Server modules:**
  - `lib/limits.js` sorts every request into **local / lan / remote**.
  - `lib/admin-auth.js` holds the per-start admin key, the scrypt-hashed Wi-Fi password and the login sessions.
  - `lib/history.js` stores finished missions in `<dataDir>/history.json`.
  - `lib/admin.js` serves `/admin`, with the key written into the page for local requests only, plus the `/api/admin/*` routes.
  - `lib/rooms.js` reports room events and gains kick, close and a live snapshot.
- **Admin page:** a static page, `admin.html` + `src/admin.js` + `src/admin.css`, that reuses the game's `style.css`, `i18n.js`, `art.js` and `charts.js`.
- **Progress data:** `tools/progress.js` generates `progress.json` for the Project tab.

**Tech Stack:** Node 24 (`node:test`, `node:crypto` scrypt), `ws` 8.22 (already installed), Electron 44 (app only). Browser code is plain JavaScript in IIFEs with no build step, using SVG charts from `src/charts.js`.

**Spec:** `docs/superpowers/specs/2026-10-01-sol500-v3-app-online-bigmap-admin-design.md` (v3.1). This plan covers §8 (admin panel), the §6 M2 changes, the §12 M2 checklist and §13 items 7–8. Also read:

## Global Constraints

- **Request classes:**
  - **remote:** `Cf-Connecting-IP` present, or a `*.trycloudflare.com` Host, or a non-private socket address.
  - **local:** a loopback socket, no `Cf-Connecting-IP`, and a Host of `localhost`, `127.0.0.1` or `[::1]` (any port).
  - **lan:** everything else.
- **Remote** requests get **404** on `/admin`, every `/api/admin/*` path and `POST /api/history/solo`, even with a valid key.
- **LAN** requests get **404** on `/admin` and `/api/admin/*` while Wi-Fi access is off.
- **Admin key:** 128 random bits (32 hex characters), new on every server start. It is only ever written into a page served to a **local** request. It's compared in constant time; a missing or wrong key gets **401**.
- **Wi-Fi password:**
  - 8–64 characters;
  - stored only as an scrypt hash (N=16384, r=8, p=1, 32-byte hash, 16-byte random salt) in `<dataDir>/admin.json`;
  - never logged.
- **Sessions:** 128-bit random tokens, expire after **8 h**, at most **20**, held in memory. Server restarts, password changes and switching Wi-Fi access off all end every session.
- **Rate limits:**
  - login: **5 per minute and 20 per hour per IP**, then 429;
  - solo history: **10 per minute per IP**, then 429.
- **What LAN admins can do:** everything except change the Wi-Fi settings and refresh the project progress. Those get **403** `localOnly`.
- **History storage:**
  - `<dataDir>/history.json`, newest first, capped at **2,000** records;
  - writes go to a temp file and are renamed into place, with a copy fallback on `EPERM`/`EBUSY`/`EACCES`;
  - a corrupt file is moved aside as `history.corrupt-<ts>.json`;
  - without a `dataDir` (tests, a server created from code) the history and admin settings are memory only;
  - the CLI uses `./data` (already git-ignored) and the app uses Electron's `userData`.
- **CSV export:** a UTF-8 BOM, every cell quoted, and *string* cells starting with `= + - @ TAB CR` prefixed with `'`.
- **Language:** every new player-facing string goes in `src/i18n.js` in **both** `en` and `vi`. `test/i18n.test.js` enforces this.
- **No new runtime dependencies.** `ws` and `qrcode` are the only ones.
- **Code style:**
  - CommonJS with `'use strict'`, 2-space indent, single quotes.
  - Every new file starts with a short header comment saying what it is for.
  - Browser files are IIFEs that attach to `window` and use no frameworks.
  - Comment density matches the surrounding code.
- **Charts** follow the dataviz rules:
  - one mark hue, `--viz-1: #3987e5` (validated: passes lightness, chroma and ≥ 3:1 contrast on `--panel` `#241b1e`);
  - a single series has no legend box;
  - the value sits at the bar tip;
  - text uses text tokens, never the mark colour;
  - every chart has a data-table view and a per-mark hover tooltip.
- **Theme:** the game has a single committed dark theme, and the admin page uses the same one.
- **Commits:** one per task. Each commit message ends with exactly this line:
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`
  Subagents must not put their own model name in the trailer.
- **Before any manual or browser test:**
  - stop any server already on port 5050 (a stale server caused the 2026-09-30 LAN bug);
  - use `PORT=5077` for QA servers.
- **After app tests:** stop leftover processes with PowerShell (Git Bash rewrites `taskkill /IM` into a path):
  `Stop-Process -Name electron,'SOL 500',cloudflared-windows-amd64 -Force -ErrorAction SilentlyContinue`

```js
const LOCAL_HOSTS = ['localhost', '127.0.0.1', '[::1]'];

// The Host header without its port: "localhost:5050" → "localhost", "[::1]:5050" → "[::1]".
function hostName(req) {
  const host = String((req.headers || {}).host || '').trim().toLowerCase();
  if (host.startsWith('[')) return host.slice(0, host.indexOf(']') + 1);
  return host.replace(/:\d+$/, '');
}

function isLoopback(req) {
  const a = socketAddress(req);
  return /^127\./.test(a) || a === '::1';
}

// Who is asking, for the admin panel:
//   'remote': through the share link, or from outside the home network (see isRemote)
//   'local':  this PC, addressed as localhost. Checking the Host header stops a web page that points its own
//             domain at 127.0.0.1 (DNS rebinding) from passing as this PC.
//   'lan':    everything else, i.e. other devices on the home Wi-Fi.
function requestClass(req) {
  if (isRemote(req)) return 'remote';
  if (isLoopback(req) && LOCAL_HOSTS.includes(hostName(req))) return 'local';
  return 'lan';
}
```

```js
'use strict';
/*
 * SOL 500 — small JSON files in the data folder, written so that a crash or a locked file never leaves half a file.
 */
const fs = require('node:fs');
const path = require('node:path');

// The parsed value; `fallback` when the file doesn't exist; throws { code: 'BAD_JSON' } when it isn't JSON.
function readJson(file, fallback, fsImpl = fs) {
  let text;
  try { text = fsImpl.readFileSync(file, 'utf8'); } catch (e) { if (e.code === 'ENOENT') return fallback; throw e; }
  try { return JSON.parse(text); } catch (e) { throw Object.assign(new Error('bad JSON in ' + file), { code: 'BAD_JSON' }); }
}

// Write a temp file, then rename it over the old one. On Windows an antivirus or the search indexer can hold the old
// file open so the rename fails (EPERM/EBUSY/EACCES): then copy over it instead.
function writeJsonAtomic(file, value, fsImpl = fs) {
  fsImpl.mkdirSync(path.dirname(file), { recursive: true });
  const tmp = file + '.' + process.pid + '.tmp';
  fsImpl.writeFileSync(tmp, JSON.stringify(value));
  try {
    fsImpl.renameSync(tmp, file);
  } catch (e) {
    if (!['EPERM', 'EBUSY', 'EACCES'].includes(e.code)) {
      try { fsImpl.unlinkSync(tmp); } catch (x) { /* ignore */ }
      throw e;
    }
    fsImpl.copyFileSync(tmp, file);
    fsImpl.unlinkSync(tmp);
  }
}

module.exports = { readJson, writeJsonAtomic };
```

```js
'use strict';
/*
 * SOL 500 — mission history for the admin panel: <dataDir>/history.json, newest first, at most `cap` records.
 * Without a dataDir (tests, or a server created from code) the history lives in memory only.
 */
const fs = require('node:fs');
const path = require('node:path');
const crypto = require('node:crypto');
const E = require('../src/engine.js');
const D = require('../src/data.js');
const { readJson, writeJsonAtomic } = require('./jsonfile.js');

const MODES = ['solo', 'lan', 'online'];
const CAUSES = ['hypoxia', 'dehydration', 'starvation', 'cold', 'habFault', 'radiationSickness', 'injury', 'rations', 'health'];
const CSV_COLUMNS = ['endedAt', 'mode', 'missionCode', 'difficulty', 'crewSize', 'players', 'outcome', 'cause', 'score', 'grade', 'sols', 'achievements'];

const roleOf = id => (D.CREW.find(c => c.id === id) || {}).role || null;
const cleanName = n => String(n == null ? '' : n).replace(/[\u0000-\u001f<>]/g, '').trim().slice(0, 24);

// A solo mission arrives from a browser that ran its own simulation: check its shape before scoring it.
function validMission(m) {
  if (!m || typeof m !== 'object' || m.version !== 2) return false;
  if (!['success', 'lost'].includes(m.status)) return false;
  if (typeof m.seed !== 'string' || !m.seed || m.seed.length > 24) return false;
  if (!D.DIFFICULTY[m.difficulty] || !D.CREW_SIZES.includes(m.crewSize)) return false;
  if (!Number.isInteger(m.turn) || m.turn < 1 || m.turn > D.TURNS) return false;
  if (![m.sol, m.science, m.mass].every(Number.isFinite)) return false;
  if (!Array.isArray(m.crew) || m.crew.length !== m.crewSize) return false;
  const ids = D.CREW.map(c => c.id);
  const crewOk = c => c && ids.includes(c.id) && Number.isFinite(c.health) && Number.isFinite(c.dose) && ['active', 'down', 'dead'].includes(c.status);
  if (!m.crew.every(crewOk)) return false;
  if (!m.totals || !m.depot || !m.modules || !m.modules.shield || !Array.isArray(m.schedule)) return false;
  try { E.scoreMission(m); E.achievements(m); } catch (e) { return false; }
  return true;
}

// One history record. players: [{ name, crewId }], the co-op seats or the solo player.
function summarize(mission, { mode, players } = {}) {
  const score = E.scoreMission(mission);
  const reason = mission.endCause && mission.endCause.reason;
  return {
    id: crypto.randomBytes(6).toString('hex'),
    endedAt: new Date().toISOString(),
    mode: MODES.includes(mode) ? mode : 'solo',
    missionCode: String(mission.seed).slice(0, 24),
    difficulty: mission.difficulty,
    crewSize: mission.crewSize,
    players: (players || []).slice(0, 5).map(p => ({ name: cleanName(p.name) || '?', crewId: p.crewId || null, role: roleOf(p.crewId) })),
    outcome: mission.status,
    cause: mission.status === 'lost' ? (CAUSES.includes(reason) ? reason : 'health') : null,
    score: score.total,
    grade: score.grade,
    sols: mission.sol,
    finds: {},
    distance: {},
    explore: { regions: 0, landmarks: 0, structures: 0, beacons: 0, goals: 0 },
    achievements: E.achievements(mission),
  };
}

function createHistory({ dataDir = null, cap = 2000, fsImpl = fs } = {}) {
  const file = dataDir ? path.join(dataDir, 'history.json') : null;
  let records = load();

  function load() {
    if (!file) return [];
    try {
      const list = readJson(file, [], fsImpl);
      if (Array.isArray(list)) return list.filter(r => r && typeof r.id === 'string').slice(0, cap);
    } catch (e) { /* unreadable: set it aside below */ }
    try { fsImpl.renameSync(file, path.join(dataDir, 'history.corrupt-' + Date.now() + '.json')); } catch (e) { /* ignore */ }
    return [];
  }

  // A full disk or a read-only folder must never break a game: keep the records in memory and say so in the log.
  function persist() {
    if (!file) return;
    try { writeJsonAtomic(file, records, fsImpl); } catch (e) { console.error('SOL 500: could not save the mission history: ' + e.message); }
  }

  return {
    list: () => records.slice(),
    add(record) {
      records.unshift(record);
      if (records.length > cap) records.length = cap;
      persist();
      return record;
    },
    remove(id) {
      const before = records.length;
      records = records.filter(r => r.id !== id);
      if (records.length === before) return false;
      persist();
      return true;
    },
    clear() { records = []; persist(); },
  };
}

// Text cells starting with = + - @ (or a tab or CR) would run as formulas in Excel: prefix them with '.
function csvCell(v) {
  let s = v == null ? '' : String(v);
  if (typeof v === 'string' && /^[=+\-@\t\r]/.test(s)) s = "'" + s;
  return '"' + s.replace(/"/g, '""') + '"';
}

function toCSV(records) {
  const rows = [CSV_COLUMNS.join(',')];
  for (const r of records) {
    rows.push(CSV_COLUMNS.map(k => {
      if (k === 'players') return csvCell((r.players || []).map(p => p.name + (p.role ? ' (' + p.role + ')' : '')).join('; '));
      if (k === 'achievements') return csvCell((r.achievements || []).join(' '));
      return csvCell(r[k]);
    }).join(','));
  }
  return '﻿' + rows.join('\r\n') + '\r\n';
}

module.exports = { createHistory, summarize, validMission, toCSV, CAUSES };
```

```js
'use strict';
/*
 * SOL 500 — who may use the admin panel.
 *   This PC:             the admin key. New on every start; only ever put into a page served to this PC.
 *   Other Wi-Fi devices: only while the host has switched Wi-Fi access on. They log in with a password (kept as an
 *                        scrypt hash in <dataDir>/admin.json) and get a session token for 8 hours.
 *   The share link:      never. lib/admin.js answers 404 before asking this module.
 */
const crypto = require('node:crypto');
const fs = require('node:fs');
const path = require('node:path');
const { promisify } = require('node:util');
const { readJson, writeJsonAtomic } = require('./jsonfile.js');

const scrypt = promisify(crypto.scrypt);
const COST = { N: 16384, r: 8, p: 1 };
const HASH_BYTES = 32;
const SESSION_MS = 8 * 60 * 60 * 1000;
const MAX_SESSIONS = 20;
const OFF = { enabled: false, salt: null, hash: null, N: COST.N, r: COST.r, p: COST.p };

const digest = s => crypto.createHash('sha256').update(String(s == null ? '' : s)).digest();
// Constant-time compare that also hides the secret's length.
const sameSecret = (a, b) => crypto.timingSafeEqual(digest(a), digest(b));
const goodPassword = pw => typeof pw === 'string' && pw.length >= 8 && pw.length <= 64;

function createAdminAuth({ dataDir = null, key = null, now = Date.now, fsImpl = fs } = {}) {
  const adminKey = key || crypto.randomBytes(16).toString('hex');
  const file = dataDir ? path.join(dataDir, 'admin.json') : null;
  const sessions = new Map(); // token → expiry time, oldest first
  let settings = load();

  function load() {
    if (!file) return Object.assign({}, OFF);
    try {
      const s = readJson(file, null, fsImpl);
      if (s && typeof s.hash === 'string' && typeof s.salt === 'string') return Object.assign({}, OFF, s, { enabled: !!s.enabled });
    } catch (e) { /* unreadable: start with Wi-Fi access off */ }
    return Object.assign({}, OFF);
  }

  function persist() {
    if (!file) return;
    try { writeJsonAtomic(file, settings, fsImpl); } catch (e) { console.error('SOL 500: could not save the admin settings: ' + e.message); }
  }

  async function setPassword(pw) {
    if (!goodPassword(pw)) return { error: 'badPassword' };
    const salt = crypto.randomBytes(16);
    const hash = await scrypt(pw, salt, HASH_BYTES, COST);
    settings = Object.assign({}, settings, { salt: salt.toString('hex'), hash: hash.toString('hex'), N: COST.N, r: COST.r, p: COST.p });
    sessions.clear();
    persist();
    return { ok: true };
  }

  function setEnabled(on) {
    if (on && !settings.hash) return { error: 'noPassword' };
    settings = Object.assign({}, settings, { enabled: !!on });
    if (!on) sessions.clear();
    persist();
    return { ok: true };
  }

  async function login(pw) {
    if (!settings.enabled || !settings.hash) return { error: 'off' };
    if (typeof pw !== 'string' || pw.length > 64) return { error: 'badPassword' };
    const want = Buffer.from(settings.hash, 'hex');
    const got = await scrypt(pw, Buffer.from(settings.salt, 'hex'), HASH_BYTES, { N: settings.N, r: settings.r, p: settings.p });
    if (want.length !== got.length || !crypto.timingSafeEqual(want, got)) return { error: 'badPassword' };
    if (!settings.enabled) return { error: 'off' }; // switched off while the hash was being worked out
    const t = now();
    for (const [tok, exp] of sessions) if (exp <= t) sessions.delete(tok);
    while (sessions.size >= MAX_SESSIONS) sessions.delete(sessions.keys().next().value);
    const token = crypto.randomBytes(16).toString('hex');
    sessions.set(token, t + SESSION_MS);
    return { token, expiresAt: t + SESSION_MS };
  }

  function sessionValid(token) {
    if (typeof token !== 'string' || !sessions.has(token)) return false;
    if (sessions.get(token) <= now()) { sessions.delete(token); return false; }
    return true;
  }

  // What this request may do: 'local' (this PC), 'lan' (a logged-in Wi-Fi device) or null.
  function authorize(cls, token) {
    if (cls === 'local') return sameSecret(token, adminKey) ? 'local' : null;
    if (cls === 'lan') return settings.enabled && sessionValid(token) ? 'lan' : null;
    return null;
  }

  function wifi() {
    const t = now();
    return { enabled: !!settings.enabled, hasPassword: !!settings.hash, sessions: [...sessions.values()].filter(e => e > t).length };
  }

  return { key: adminKey, authorize, login, setPassword, setEnabled, logoutAll: () => sessions.clear(), wifi };
}

module.exports = { createAdminAuth };
```

```js
'use strict';
// SOL 500 — the two HTTP helpers every route uses: a JSON reply and a size-capped JSON body reader.
const MAX_BODY = 64 * 1024;

function send(res, status, obj, headers) {
  res.writeHead(status, Object.assign({ 'Content-Type': 'application/json; charset=utf-8', 'Cache-Control': 'no-store' }, headers));
  res.end(JSON.stringify(obj));
}

function readBody(req) {
  return new Promise((resolve, reject) => {
    const tooBig = () => Object.assign(new Error('tooBig'), { status: 413 });
    if (Number(req.headers['content-length']) > MAX_BODY) { req.resume(); reject(tooBig()); return; }
    let size = 0;
    let over = false;
    const chunks = [];
    req.on('data', c => {
      size += c.length;
      if (size > MAX_BODY) { over = true; chunks.length = 0; return; }
      chunks.push(c);
    });
    req.on('end', () => {
      if (over) { reject(tooBig()); return; }
      try { resolve(JSON.parse(Buffer.concat(chunks).toString('utf8') || '{}')); } catch (e) { reject(e); }
    });
    req.on('error', reject);
  });
}

module.exports = { send, readBody, MAX_BODY };
```

```js
      if (r.error) { send(res, 400, r); return; }
    }
    if (body.enabled != null) {
      const r = auth.setEnabled(!!body.enabled);
      if (r.error) { send(res, 400, r); return; }
    }
    send(res, 200, auth.wifi());
  });
  route('POST', '/api/admin/wifi/logout', 'local', ({ res }) => { auth.logoutAll(); send(res, 200, auth.wifi()); });

  // true when the request was an admin request and has been answered.
  async function handle(req, res, url, cls, ip) {
    const p = url.pathname;
    if (p !== '/admin' && !p.startsWith('/api/admin/')) return false;
    const notFound = () => send(res, 404, { error: 'notFound' });
    if (cls === 'remote') { notFound(); return true; }
    if (cls === 'lan' && !auth.wifi().enabled) { notFound(); return true; }
    if (req.method === 'GET' && p === '/admin') { page(res, cls); return true; }
    if (req.method === 'POST' && p === '/api/admin/login') { await login(req, res, cls, ip); return true; }
    const r = routes.get(req.method + ' ' + p);
    if (!r) { notFound(); return true; }
    const role = auth.authorize(cls, req.headers['x-admin-key']);
    if (!role) { send(res, 401, { error: 'unauthorized' }); return true; }
    if (r.who === 'local' && role !== 'local') { send(res, 403, { error: 'localOnly' }); return true; }
    const body = req.method === 'POST' ? await readBody(req) : null;
    await r.fn({ req, res, role, body, url });
    return true;
  }

  return { key: auth.key, handle, route };
}
```

```js
#!/usr/bin/env node
// Writes progress.json for the admin panel's Project tab: the spec's feature checklist, test results, recent commits,
// code size and the science sources. `npm run progress`; `npm run app` runs it first so the app ships a snapshot.
//   node tools/progress.js [--out path/to/progress.json]
'use strict';
const fs = require('node:fs');
const path = require('node:path');
const { spawnSync } = require('node:child_process');

const ROOT = path.join(__dirname, '..');
const SPEC = 'docs/superpowers/specs/2026-10-01-sol500-v3-app-online-bigmap-admin-design.md';
const CODE = /\.(js|css|html)$/;

// "## 12. Feature checklist": "### M2 — Admin panel" headings, then "- [ ] text" / "- [x] text" lines.
function parseChecklist(md) {
  const milestones = [];
  const features = [];
  let inList = false;
  let current = null;
  for (const line of md.split(/\r?\n/)) {
    if (/^## 12\./.test(line)) { inList = true; continue; }
    if (inList && /^## /.test(line)) break;
    if (!inList) continue;
    const head = line.match(/^### (M\d+)\s*[—-]\s*(.+)$/);
    if (head) { current = head[1]; milestones.push({ id: head[1], title: head[2].trim() }); continue; }
    const item = line.match(/^- \[( |x|X)\] (.+)$/);
    if (item && current) features.push({ milestone: current, text: item[2].trim(), done: item[1] !== ' ' });
  }
  return { milestones, features };
}

// node --test --test-reporter=tap ends with "# tests 107", "# pass 107", "# fail 0".
function parseTap(text) {
  const num = k => { const m = String(text).match(new RegExp('^# ' + k + ' (\\d+)', 'm')); return m ? Number(m[1]) : 0; };
  return { total: num('tests'), pass: num('pass'), fail: num('fail') };
}

// git log --format=%h%x09%cs%x09%s
function parseGitLog(text) {
  return String(text).split('\n').filter(Boolean).map(line => {
    const [hash, date, ...rest] = line.split('\t');
    return { hash, date, subject: rest.join('\t') };
  });
}

function lineCount(file) {
  let text;
  try { text = fs.readFileSync(file, 'utf8'); } catch (e) { return 0; }
  if (!text) return 0;
  return text.split('\n').length - (text.endsWith('\n') ? 1 : 0);
}

// Failing tests make `node --test` exit non-zero, but its output still has the counts we want.
function run(cmd, args) {
  const r = spawnSync(cmd, args, { cwd: ROOT, encoding: 'utf8', maxBuffer: 64 * 1024 * 1024, windowsHide: true });
  return r.error ? '' : r.stdout || '';
}

function build() {
  const { milestones, features } = parseChecklist(fs.readFileSync(path.join(ROOT, SPEC), 'utf8'));
  const tests = parseTap(run(process.execPath, ['--test', '--test-reporter=tap']));
  const count = Number(run('git', ['rev-list', '--count', 'HEAD']).trim()) || 0;
  const recent = parseGitLog(run('git', ['log', '-10', '--format=%h%x09%cs%x09%s']));
  const files = run('git', ['ls-files']).split('\n').filter(f => CODE.test(f) && !f.startsWith('dist/'))
    .map(f => ({ path: f, lines: lineCount(path.join(ROOT, f)) })).sort((a, b) => b.lines - a.lines);
  const I = require('../src/i18n.js');
  return {
    generatedAt: new Date().toISOString(),
    milestones, features, tests,
    commits: { count, recent },
    code: { files, total: files.reduce((n, f) => n + f.lines, 0) },
    sources: Object.values(I.SOURCES).map(s => ({ label: s.label, url: s.url })),
  };
}

if (require.main === module) {
  const at = process.argv.indexOf('--out');
  const out = at > 0 && process.argv[at + 1] ? path.resolve(process.argv[at + 1]) : path.join(ROOT, 'progress.json');
  const p = build();
  fs.writeFileSync(out, JSON.stringify(p, null, 2));
  const done = p.features.filter(f => f.done).length;
  console.log(`progress.json: ${done}/${p.features.length} features · tests ${p.tests.pass}/${p.tests.total} · ${p.commits.count} commits · ${p.code.total} lines`);
}

module.exports = { parseChecklist, parseTap, parseGitLog, lineCount };
```

```js
  // Horizontal bars for counts per category: one hue (it's magnitude, not identity), bars no thicker than 18 px,
  // square at the baseline with a 4 px rounded tip, the value right after the tip, a tooltip per bar, and the table view.
  function barChart(container, cfg) {
    const fmt = cfg.fmt || (v => Math.round(v).toLocaleString());
    const rows = cfg.rows || [];
    const BAND = 30, BAR = 18, LW = 160, RW = 64, BW = 640;
    const BH = Math.max(1, rows.length) * BAND + 8;
    const max = Math.max(1, ...rows.map(r => r.value));
    const len = v => (Math.max(0, v) / max) * (BW - LW - RW);

    const wrap = document.createElement('div');
    wrap.className = 'chart';
    const svg = el('svg', { viewBox: `0 0 ${BW} ${BH}`, role: 'img', 'aria-label': cfg.title || '' });
    el('title', {}, svg).textContent = cfg.title || '';
    el('line', { x1: LW, x2: LW, y1: 2, y2: BH - 2, stroke: 'var(--line)', 'stroke-width': 1 }, svg);
    const tip = document.createElement('div');
    tip.className = 'tip';
    tip.hidden = true;

    rows.forEach((r, i) => {
      const top = 4 + i * BAND;
      const y = top + (BAND - BAR) / 2;
      const w = len(r.value);
      const label = el('text', { x: LW - 10, y: y + BAR / 2 + 4, 'text-anchor': 'end', fill: 'var(--fg-2)', 'font-size': 12 }, svg);
      label.textContent = r.label;
      if (w > 0) {
        const rr = Math.min(4, w, BAR / 2);
        const x2 = LW + w;
        const d = `M${LW} ${y} H${x2 - rr} Q${x2} ${y} ${x2} ${y + rr} V${y + BAR - rr} Q${x2} ${y + BAR} ${x2 - rr} ${y + BAR} H${LW} Z`;
        el('path', { d, fill: cfg.color }, svg);
      }
      const value = el('text', { x: LW + w + 8, y: y + BAR / 2 + 4, fill: 'var(--fg)', 'font-size': 12, 'font-family': 'var(--font-data)' }, svg);
      value.textContent = fmt(r.value);
      const hit = el('rect', { x: 0, y: top, width: BW, height: BAND, fill: 'transparent' }, svg);
      const show = () => {
        tip.textContent = '';
        const b = document.createElement('b');
        b.textContent = fmt(r.value);
        tip.append(r.label + ' ', b);
        tip.hidden = false;
        tip.style.left = ((LW + w) / BW) * 100 + '%';
        tip.style.top = (top / BH) * 100 + '%';
      };
      hit.addEventListener('pointermove', show);
      hit.addEventListener('pointerdown', show);
      hit.addEventListener('pointerleave', () => { tip.hidden = true; });
    });

    wrap.appendChild(svg);
    wrap.appendChild(tip);
    const det = document.createElement('details');
    const sum = document.createElement('summary');
    sum.className = 'hint';
    sum.textContent = cfg.tableLabel || 'Data table';
    det.appendChild(sum);
    const tw = document.createElement('div');
    tw.className = 'tablewrap';
    const table = document.createElement('table');
    table.className = 'log';
    const tb = table.createTBody();
    for (const r of rows) {
      const tr = tb.insertRow();
      tr.insertCell().textContent = r.label;
      tr.insertCell().textContent = fmt(r.value);
    }
    tw.appendChild(table);
    det.appendChild(tw);
    wrap.appendChild(det);
    container.appendChild(wrap);
    return wrap;
  }
```

```js
#!/usr/bin/env node
// Fills a data folder with finished missions so the admin panel has something to show: every record is a real game
// played by the engine (default plan, different seeds and settings), spread over the past days.
//   node tools/seed-history.js --dir data-demo [--n 40]
'use strict';
const path = require('node:path');
const D = require('../src/data.js');
const E = require('../src/engine.js');
const { createHistory, summarize } = require('../lib/history.js');

const arg = (name, d) => { const i = process.argv.indexOf('--' + name); return i > 0 && process.argv[i + 1] ? process.argv[i + 1] : d; };
const dir = path.resolve(arg('dir', 'data-demo'));
const n = Math.max(1, Math.min(2000, Number(arg('n', 40)) || 40));
const NAMES = ['Linh', 'Bảo', 'Nguyễn Thị Ánh', 'Diego', 'Amara', '<b>Kai</b>', 'Minh', '=SUM(A1)'];
const MODES = ['solo', 'lan', 'online'];
const history = createHistory({ dataDir: dir });
const diffs = Object.keys(D.DIFFICULTY);

for (let i = 0; i < n; i++) {
  const difficulty = diffs[i % diffs.length];
  const crewSize = D.CREW_SIZES[i % D.CREW_SIZES.length];
  let s = E.createMission({ seed: 'DEMO-' + (1000 + i), loadout: E.referenceKit(difficulty, crewSize), difficulty, crewSize });
  let plan = E.defaultPlan(s);
  while (s.status === 'active') { const r = E.resolveTurn(s, plan); s = r.state; plan = E.nextPlan(s, plan); }
  const mode = MODES[i % MODES.length];
  const seats = mode === 'solo' ? 1 : 2 + (i % 3);
  const players = s.crew.slice(0, seats).map((c, k) => ({ name: NAMES[(i + k) % NAMES.length], crewId: mode === 'solo' ? null : c.id }));
  const rec = summarize(s, { mode, players });
  rec.endedAt = new Date(Date.now() - (n - i) * 3 * 3600 * 1000).toISOString();
  history.add(rec);
}
console.log(`${n} missions written to ${path.join(dir, 'history.json')}`);
```
